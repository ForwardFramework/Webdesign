# Project photos

Drop finished-project photos here, then add an entry for each one in
`data/gallery.mjs`. Files in this folder are copied straight into the deployed
site at `/assets/img/gallery/`.

- Resize to about **1600px wide** and save as JPEG at ~75% quality.
- Name them descriptively: `driveway-cranberry-2025.jpg`, not `IMG_4471.jpg`.
- Before/after pairs from the same angle convert better than finished shots alone.
- Shoot after cleanup, in flat light or late afternoon — midday glare washes out
  the texture that makes good concrete look good.
